# Contributing

Feature development is paused. The current scope is retained as a learning and
portfolio project. There is no active feature roadmap or support SLA.

Reproducible bug reports, security reports, and documentation correction suggestions
are welcome. Do not submit code changes or pull requests without prior written
permission. The project is source-available, and its license does not grant rights
to modify or redistribute the source.

For a bug report, include the commit or package version, OS, .NET SDK, command,
expected result, actual result, and sanitized evidence. Do not attach API keys,
private source, or proprietary benchmark data. Report security issues through
[SECURITY.md](SECURITY.md).

If a contribution is explicitly approved, licensing and ownership terms must be
agreed in writing before any code is submitted. Keep third-party notices intact.
For project maintenance requirements, see [CI policy](docs/ci-policy.md) and the
[release checklist](docs/maintenance/release-checklist.md).
