# Third-party notices

This inventory covers the 31 resolved runtime package/version entries for the CLI
and bundled BenchmarkHost, reviewed on 2026-10-06. NuGet metadata declares MIT for
these packages, including two file-based MIT declarations. This is not a statement
that every bundled native component or upstream notice is MIT.

Original legal files are preserved in [licenses](licenses), with per-package sources
and SHA-256 hashes in [manifest.json](licenses/manifest.json). Duplicate legal texts
share one file. Packaged notices travel with the dotnet tool. Refresh this inventory
whenever resolved dependencies change. Test/build-only dependencies and the separately
installed .NET SDK/shared frameworks are outside this runtime distribution inventory.

## Native and additional upstream material

- Gee.External.Capstone is an MIT .NET binding that bundles Capstone 4 native binaries.
  Preserve the Capstone BSD-style license and its LLVM notice as well as the binding license.
- TraceEvent bundles Windows support binaries (KernelTraceControl and msdia140) through
  its upstream NuGet package. The versioned upstream license is retained. This project
  does not claim authorship or separately relicense those files.
- Roslyn and several Microsoft packages ship additional third-party notices; the original
  TXT/RTF files are preserved, including notices with terms other than MIT.
- Pragmastat code is MIT. Its upstream license also discusses separately licensed manual
  content; that manual is not redistributed as part of this tool.
